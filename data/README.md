## Dataset

This project uses synthetic healthcare data generated by Synthea.

This repository excludes the raw CSV files because of their size. Download
`synthea_sample_data_csv_nov2021.zip` from the
[Synthea sample-data repository](https://github.com/synthetichealth/synthea-sample-data).

Required files:

- patients.csv
- encounters.csv
- conditions.csv
- providers.csv
- organizations.csv
- payers.csv

Extract the required files into the local `data` folder. Update the SQL Server
`BULK INSERT` paths to match the location of the repository on your computer.
